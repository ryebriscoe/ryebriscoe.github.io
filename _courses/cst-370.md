In progress during Fall 2026, Term A. All homework is done, with the final exam left.

Every week was a Java program graded against hidden test cases, so the output had to match exactly and the edge cases had to hold up. The work started with basics like min, max, and median, then moved into the real material:

- **Brute force:** closest pair of numbers, intersecting a set of ranges, and generating every subset of a set using binary counting
- **Graphs:** storing a weighted graph as an adjacency list, using DFS to find disconnected pieces of a graph and the edges needed to join them, topological sort with Kahn's algorithm, and a BFS that finds everyone exactly N degrees away from a person in a social network
- **Heaps and hashing:** checking and building a max heap, plus a hash table with linear probing that rehashes when it fills up
- **Dynamic programming:** the robot coin collection problem and Floyd's algorithm for all pairs shortest paths

The biggest change for me was thinking about efficiency before writing any code instead of after.
