Two strands of work, one building a processor up from gates and the other programming one directly.

**Logic design.** Six labs building hardware in HDL, starting from NAND alone. Lab 1 covered NAND conversions, then elementary gates (Not16, And16, Or16, Or8Way, Xor, Mux, Mux16, Mux4Way16, DMux, DMux4Way, DMux8Way), then combinational chips, then sequential chips. Every gate had to be built out of gates already built, so nothing could be assumed.

**Assembly programming.** MIPS assembly written and run in the MARS simulator, including a Madlibs program and a Fibonacci series using arrays, plus assignments on branching, loops, and procedure calls.

**x86 MASM.** The transfer course at West Valley covered the same ideas in x86, with five labs on data representation, registers, addressing modes, and control flow against the Microsoft macro assembler toolchain.
