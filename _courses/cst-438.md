A course registration and grading platform built as a three service system by team 03, deployed to AWS EC2.

The work is split across three repositories:

- **[Registrar service](https://github.com/cst438-team03-org0/cst438-team-03-registrar)** in Java, handling enrollment, course sections, and student records
- **[Gradebook service](https://github.com/cst438-team03-org0/cst438-team03-gradebook)** in Java, handling assignments and grade entry
- **[Frontend](https://github.com/cst438-team03-org0/cst438-team03-frontend)** in JavaScript, the interface both services sit behind

Splitting registrar and gradebook into separate services meant the two teams working on them could deploy independently, and it forced the boundary between them to be an actual API contract rather than a shared object graph. The whole system was deployed to EC2 rather than only running locally, which is where most of the configuration work went.
