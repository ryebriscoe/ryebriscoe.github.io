*Listed in the CSUMB catalog as "Problm-Solving/Programng".*

Twenty nine programs written in JavaScript and run in the browser, grouped one folder per homework set. The course moves in order, so the work tracks the fundamentals as they arrive. Variables and input first, then conditionals and loops, then functions, arrays, and sets.

The later ones are the ones worth looking at. A binary to decimal converter, a run length decompressor, a two dimensional matrix program, and a set implementation.
