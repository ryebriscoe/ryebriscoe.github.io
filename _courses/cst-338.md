A JavaFX desktop application built by a four person team, Return of the Java, with Brianna Tomasek, Jessica Sandoval, and Vincent Marinello-Sweeney.

The app handles login and user registration across separate scenes. I wrote the scene architecture: `Main`, the `SceneType` enum, and `SceneFactory`, an abstract factory that builds and returns the right `Scene` for a given type. Adding a screen means writing one scene class, adding a case to the factory, and adding a value to the enum, so the routing stays in one place instead of being scattered through the UI code.

`LoginScene` and `RegistrationScene` implement the two screens, and the factory throws on an unrecognized scene type rather than failing silently. JUnit tests cover both the factory and the login scene.

Earlier in the course I also built a full Solitaire game in Java and JavaFX across staged milestones, with JUnit coverage at each layer for the card and deck models, the tableau and foundation rules, and game orchestration. That repository is private under the course GitHub organization.
