Four systems projects in C, building the parts an operating system is actually made of.

A growable string library with manual memory management. A CPU scheduler that runs the same workload through FIFO, Round Robin, Shortest Job First, and Priority so the tradeoffs show up in the numbers. A memory management unit implementing both base and bounds and full paging, with real process isolation. And a working `malloc` and `free` replacement with switchable first, best, and worst fit strategies.

Close to a thousand lines of C, and the clearest look I have had at what runs underneath everything else.
