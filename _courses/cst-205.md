A Wordle-style soccer trivia game built with Python and Flask. The app pulls player data from a third-party sports API, serves a guess-and-feedback game loop over HTTP, and renders results in the browser.

A second project from this course, [image-search-app](https://github.com/ryebriscoe/image-search-app), pairs a Flask backend with a PySide6 desktop GUI for image search and processing.
